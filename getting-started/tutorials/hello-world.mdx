# Tutorial: Hello World

This is the smallest program you can run.

```metel
fun main() {
    println("hello, Metel");
}
```

The important part is the `main` function. The interpreter looks for it as the entry point.

## Try it

Save the program as `hello.mln`, then run it with:

```bash
cargo run -- path/to/hello.mln
```

## Why this matters

- `fun` defines a function.
- `main` is the entry point.
- `println` is one of the built-in functions available from the runtime.

Once this works, move on to the next tutorial to add types and data.
