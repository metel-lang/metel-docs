# Getting started with Metel

**Metel is a clean-slate language for compile-time safety** — a research language with
no backward-compatibility obligations, where the ideas behind static safety get
redesigned rather than patched around. In practice that means precise data shapes
(records and structs whose types change as fields move in and out), row-polymorphic
bounds, an explicit closure-capture model, and positive *and* negative capability
bounds. The interpreter and the RFCs are still moving; this section is the practical
on-ramp.

## Pick a path

- **[Quickstart](quickstart)** — the shortest route from a blank file to a running
  program.
- **[The tutorial](tutorials/first-run)** — a nine-step build. You write one small
  project, `metrics`, and each step adds a stage. This is where the distinctive
  parts of the language show up in context rather than as a feature list.
- **[Reference pages](tutorials/numbers-chars-and-collections)** at the end of the
  tutorial section — numerics, the standard library, control-flow detail — to dip
  into as needed.

For the normative detail, the [language specification](../reference/spec) is the
source of truth, and the [error catalog](../reference/error-codes) lists every
diagnostic the compiler and runtime can produce.
