## Findings

- **metel-core#958** — row narrowing is not path-sensitive across `if` / `match` arms in
  the typechecker: both arms run against one shared `FlowState`, with no per-arm
  fork and no `union_from` join. A later arm sees an earlier arm's partial move, and a
  one-arm move taints every later path. Over-rejection only — no unsoundness, the default
  evaluator runs the programs, `--move-check` is unaffected. **Deferred to v0.13.1.** The
  v0.13.0 changelog's "path-sensitive, joined across `if` / `match` arms" wording is
  softened to match what shipped (paired doc change in this session).
- **metel-core#959** — the T0028 message for a `&var` capture without the `var` qualifier
  tells the user to write `[...] var (...)`, the parenthesized closure spelling RFC-0154
  removed this same milestone. Cosmetic. **Deferred to v0.13.1.**
- **metel-core#960** — pre-existing, surfaced here: `cargo test --test integration` aborts
  the whole binary with a stack overflow under the **debug** profile
  (`module_semantics__intra_module_recursion_visible_after_cross_module_import`), the
  `ctx.solve()` recursion depth resurfacing. `--release` — the CI gate and `/cut-release`
  Step 2 item 8 — passes it in 0.33s. Breaks `cargo test --workspace` for contributors,
  not the release. **Deferred to v0.13.1.**
