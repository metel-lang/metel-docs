## Findings

- **metel-core#958 — FIXED (this session).** Row narrowing was not path-sensitive across
  `if` / `match` arms: both passes ran every arm against one shared `FlowState`, no
  per-arm fork, no `union_from` join, so a later arm saw an earlier arm's partial move
  and RFC-0117 / RFC-0137's "joined across arms" property was unimplemented. Fixed by
  forking each arm from the pre-construct move state and joining (union) afterward, in
  `Expr::If` and `infer_match` / `construct_match` of both passes. The v0.13.0 changelog
  bullet is restored to state that path-sensitivity works. Over-rejection only — no
  unsoundness — but pulled into v0.13.0 so the shipped behaviour matches the spec, which
  already specified the fork/join.
- **metel-core#959 — FIXED (this session).** The T0028 `&var`-capture-without-`var`
  message told the user to write `[...] var (...)`, the parenthesized closure spelling
  RFC-0154 removed this same milestone. Now names the pipe spelling
  `[...] var |...| { ... }`; new fixture covers the branch.
- **metel-core#960 — FIXED (this session).** Pre-existing, surfaced here:
  `cargo test --test integration` aborted the whole binary with a stack overflow under
  the **debug** profile (`module_semantics__intra_module_recursion_visible_after_cross_module_import`).
  Instrumented: **not** the typechecker's substitution walk (`apply` never exceeds
  recursion depth ~25 there) — it is `evaluator::eval_expr`, a `match` over every
  `TypedExpr` variant whose debug stack frame is ~60 KB (all arms' locals reserved at
  once); a ~10-deep recursive function overflows libtest's 2 MiB worker thread.
  `--release` packs the frame, so CI stayed green while `cargo test --workspace` was
  broken. Splitting `eval_expr` into per-arm helpers (was metel-core#965) shrank the
  debug frame but a clean A/B benchmark measured a ~20 % eval-throughput regression in
  release — rejected. Fixed instead by running each fixture on an **8 MiB** thread
  (the shipped `metel` binary's main-thread budget); the whole corpus passes with margin
  at zero runtime cost. #965 re-scoped to record the rejection.
